# מדריך הגדרה ל-Key User: שדרוג התצוגה ב-Web Client בלי קוד

סביבה: SAP Business One 10.0 FP 2608, Microsoft SQL Server.

> הערה על SQL Server: ה-Overview וה-Chart tiles האנליטיים (Analytical Cards) מבוססי Semantic Layer זמינים רק בגרסת HANA.
> ב-SQL Server משתמשים ב-**General Overview**, ב-**User-Defined Queries** שמוצגות כ-List View, וב-**Linked List Views**.
> השאילתות המוכנות נמצאות ב-[`../sql/queries`](../sql/queries).

## 1. דף בית לפי תפקיד

לכל משתמש יש דף בית אישי. מומלץ לבנות דף בית לדוגמה לכל תפקיד ולהדריך את המשתמשים לשכפל אותו.

1. תפריט המשתמש (למעלה) ← **Edit Home Page**.
2. **Add Group** בין הקבוצות כדי ליצור קבוצה חדשה, למשל "המשימות שלי היום".
3. על אריח ריק ← **Open App Finder** ← בחירת האפליקציות לקבוצה.
4. גרירת אריחים לסידור מחדש, ו-X על אריח כדי להסיר.

| תפקיד | קבוצות ואריחים מומלצים |
|---|---|
| מכירות | הצעות מחיר פתוחות, הזמנות פתוחות, View "הזמנות שלא סופקו" (שאילתה 03), לקוחות מעל מסגרת אשראי (שאילתה 05), Opportunities |
| רכש | בקשות רכש, הזמנות רכש פתוחות, קבלות סחורה, פריטים מתחת למינימום (שאילתה 04) |
| כספים | חשבוניות פתוחות, גיול חובות (שאילתה 01), מכירות לפי חודש (שאילתה 02), תקבולים |
| מחסן | משלוחים פתוחים, העברות מלאי, פריטים מתחת למינימום |
| הנהלה | General Overview, מכירות לפי חודש, טופ 20 לקוחות (שאילתה 06), My Approvals |

## 2. Views בדוחות רשימה (List Views)

בכל List View (הזמנות, חשבוניות, פריטים, שותפים עסקיים):

1. **View Settings**: בחירת עמודות, סדר, מיון וקיבוץ.
2. **Adapt Filters**: אילו שדות מופיעים בשורת הסינון.
3. שמירה כ-View חדש. **Public** = כל המשתמשים רואים אותו; אפשר להגדיר אותו כברירת מחדל.
4. **Share ← Save as Tile**: הוספת ה-View כאריח עם מונה רשומות לדף הבית.

Views מומלצים להתחלה:
- הזמנות לקוח: "פתוחות, תאריך אספקה עבר", מקובצות לפי איש מכירות.
- חשבוניות לקוח: "פתוחות מעל 60 יום", ממוינות לפי סכום.
- פריטים: "במלאי מתחת למינימום", מקובצות לפי קבוצת פריט.

ניתן להעביר Views בין משתמשים ובין חברות דרך האפליקציה **Export and Import Views**.

## 3. שאילתות כאפליקציות (User-Defined Queries)

1. דף הבית ← קבוצת **Analytics** ← **User-Defined Queries**.
2. יצירת שאילתה חדשה והדבקת ה-SQL מהקובץ המתאים ב-`sql/queries`.
3. שמירה בקטגוריה "FIORRI KPI". השאילתה מוצגת כ-List View רגיל, עם סינון, קיבוץ, גרף ו-Save as Tile.
4. **Linked List Views**: קישור השאילתה לכרטיס לקוח / פריט, כך שהיא נפתחת מסוננת מתוך הכרטיס.

> ב-Web Client אפשר לערוך רק שאילתות **בלי פרמטרים בזמן ריצה** (`[%0]`). לכן השאילתות בריפו כתובות בלי פרמטרים, והסינון נעשה ב-List View.

הרשאה: ב-SAP B1 קליינט ← General Authorizations ← User-Defined Queries, Export and Import Views, Linked List Views.

## 4. שדות ואובייקטים מוגדרי משתמש

- **UDF**: מוגדרים בקליינט השולחני (Tools ← Customization Tools ← User-Defined Fields - Management) ומופיעים ב-Web Client בכרטיס המסמך.
- **UDO**: אובייקט מוגדר משתמש עם טבלאות UDT. ב-Web Client הוא מקבל List View ו-Detailed View משלו.
- **UDV** (Formatted Search): ערך ברירת מחדל או רשימת בחירה מתוך שאילתה לשדה.
- הזזה, הסתרה ושינוי פריסה של שדות קיימים בכרטיס מסמך נעשים דרך **UI API Extension** (שלב הפיתוח), לא מתוך המסך.

## 5. ערכת עיצוב ושפה

תפריט המשתמש ← **Settings ← Appearance ← Theme**:
- מומלץ: **Morning Horizon** (בהיר, מודרני) או **Evening Horizon** (כהה).
- ניגודיות גבוהה זמינה למשתמשים שצריכים.

שפה: Settings ← Language ← עברית (התצוגה עוברת ל-RTL).

## 6. אישורים (Approvals)

1. בקליינט השולחני: Administration ← Approval Process ← Approval Stages + Approval Templates.
2. שלבים מומלצים: הזמנת רכש מעל סכום X; הזמנת לקוח עם הנחה מעל Y%; לקוח מעל מסגרת אשראי.
3. המאשרים עובדים מה-Web Client: אריח **My Approvals** בדף הבית, גם מהנייד.
4. התראות: Settings ← Notifications, ומייל דרך הגדרות ההתראות של השרת.

## 7. לוגו החברה

אין ב-Web Client הגדרה מובנית להחלפת הלוגו בכותרת (הלוגו של SAP בכותרת משמש לחזרה לדף הבית).
הפתרון: אריח מותאם "דף הבית של החברה" שמציג את הלוגו וקישורים מהירים. ראו [`../extensions/home-logo-tile`](../extensions/home-logo-tile).
